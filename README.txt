BUILD THE APK WITHOUT ANDROID STUDIO
1. Create a free GitHub account, make a new repository (private is fine).
2. Upload ALL contents of this folder (including the hidden .github folder) to the repo's main branch.
   Easiest: unzip, then on the repo page use "Add file > Upload files" and drag everything in.
3. Open the repo's "Actions" tab > "Build APK" > wait ~5 minutes for the green check.
4. Open the finished run, download the "ESP32Hub-apk" artifact (zip), extract app-debug.apk.
5. Copy it to the phone, open it, allow "Install unknown apps" when asked.
